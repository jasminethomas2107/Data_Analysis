# Concrete Compressive Strength Dashboard

## Project Overview

An interactive **Streamlit dashboard** for analysing concrete mixture data and predicting concrete compressive strength using **Linear Regression**.

## Technologies Used

* Python
* Pandas
* Streamlit
* Plotly
* Scikit-learn

## Features

* Interactive concrete strength prediction
* Data visualization
* Correlation analysis
* Statistical analysis
* Linear Regression model
* R² Score and MAE evaluation

## Input Parameters

* Cement
* Slag
* Ash
* Water
* Superplasticizer
* Coarse Aggregate
* Fine Aggregate
* Age
